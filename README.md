# Imperium

This repository holds two RimWorld mods, each in a folder of its own:

- `Imperium/`: Imperium, a remake of Royalty, which requires Royalty.
- `Mantle/`: Mantle, the framework layer that Imperium builds on, a mod of its own that requires no expansion.

Each mod goes into the game's `Mods` folder by its own folder.
