# Reading notes: C15

Files: 18 · Lines read: all

Short names used below in the Files table only; statements carry the full path.

Notes on the ledger-derived files (`designs/做法史/*.md`): each is a list of ruling titles regenerated from the ledger ("ledger sync … 不手改", e.g. `Imperium-Knowledge/designs/做法史/罗马城·城内.md` L4). A line gives the ruling id (R-MMDD-HHMM), a title, whether it is 现行 (in force), 部分 (partly replaced), 被替下 (replaced), and which later rulings replaced it, each with a short quote of what changed. The same ruling often repeats across the four Roman files; each is recorded once, at its first file in the order 城内, 墙, 墙外, 河与水, with later lines named only where they add something. Many lines in the source are cut at a fixed width inside the source file itself (checked: the cut is in the file, not in the reader); those are marked "(line cut in source)". Ruling ids are kept in the pointer; deciders are not named in these files unless noted.
