# The core

This section covers the core: the starting ruins the colony takes it from, the uses the colony puts it to, and how it
is kept when the building that holds it is lost. What taking the core sets off, the first meeting with the Empire and
joining it, is in [relations.md](relations.md); excavations, claims and the analysis of the old empire's technology
are in [ruins-and-technology.md](ruins-and-technology.md); Mantle, which generates the ruins, is in
[mantle.md](mantle.md); the ultraheavy mechanoid is in [mechanoids.md](mechanoids.md).

## The starting ruins

Early in the game, a quest that does not expire leads the player to the starting ruins (起始遗迹) near the colony
(`docs/core.md` L8-16, L59-60). Mantle generates them, different in each game, on the model of a small or middle-sized
town of the old empire, and players see only a decayed town, not the old empire (`docs/core.md` L10, L21-23, L61-62).
The starting ruins hold the core, the colony takes it from them, and they disappear once it is taken (`docs/core.md`
L11, L24-25, L63). Taking the core is an early goal close to the colony and sets off the colony's first meeting with
the Empire (`docs/core.md` L13). The terminal in the ruins stays in the game under a new name
(`.github/deprecated-terms.json` L537-556, L1015-1027).

## Uses

The colony puts the core to the use that its relation to the Empire calls for, and it can also sell the core
(`docs/core.md` L25-30). A colony outside the Empire puts it into the analysis device, which analyzes the old empire's
technology more slowly than the imperial insignia (帝国徽记) does (`docs/core.md` L38-40, L69-71). Making the analysis
device unlocks with the colony's first excavation other than the starting ruins (`docs/ruins-and-technology.md` L75-76).
Where Biotech is active, the core can go into an ultraheavy mechanoid (`docs/core.md` L28, L72). The colony can sell the
core to other factions (`docs/core.md` L40, L73); `docs/empire-relations.md` L98 lists selling the core as well.

> [!WARNING]
> **Conflict**: whether the colony keeps the core when it joins the Empire; no passage says how the two statements below
> fit together.
> - The colony joins by handing the core over: to the envoy at the first meeting, or later at an imperial settlement
>   once its ill will is back at zero (`docs/empire-relations.md` L10-11, L20-21, L58-59, L67-70, L76-77).
> - The imperial insignia, which the colony makes when it joins the Empire, uses the core and reads techprints, and the
>   insignia holds the core recovered from the imperial ruins (`docs/core.md` L27, L36-37, L67-68; `docs/glossary.md`
>   L57).

## Keeping the core

The core cannot be destroyed (`docs/core.md` L77). When the building that holds the core is destroyed, the core drops,
and when the colony deconstructs that building, the core is returned to it, so the core can move from one use to
another (`docs/core.md` L42-55, L78-80).
